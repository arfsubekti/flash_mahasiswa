# ⚡ Flash Mahasiswa

**Flash Mahasiswa** adalah aplikasi web berbasis [Flask](https://flask.palletsprojects.com/) yang dirancang untuk mengelola data mahasiswa secara cepat dan efisien. Cocok digunakan untuk kebutuhan akademik, administrasi kampus, maupun keperluan pembelajaran.

---

## 🚀 Fitur Utama

- ✅ Tambah, edit, hapus data mahasiswa
- 🔍 Pencarian data mahasiswa dengan cepat
- 🔐 Login sederhana untuk otorisasi
- 💾 Penyimpanan data menggunakan SQLite
- 🖥️ Antarmuka yang simpel dan responsif

## 🛠️ Cara Menjalankan Aplikasi

### 1. Clone Repository

```bash
git clone https://github.com/arfsubekti/flash_mahasiswa.git
cd flash_mahasiswa


2. Aktifkan Virtual Environment

python3 -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

3. Install Dependencies

pip install -r requirements.txt

4. Jalankan Aplikasi

python app.py (Akses di browser: http://localhost:5000)
